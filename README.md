# Aurelia Hotel & Estate

A responsive multi-page hotel website built with HTML, CSS, and Bootstrap.

## Features

* Responsive design for different screen sizes
* Multi-page hotel website layout
* Rooms and facilities sections
* Restaurant and booking pages
* Gallery section
* Responsive navigation
* Custom styling and layouts

## Technologies Used

* HTML5
* CSS3
* Bootstrap

## Live Demo

https://aurelia-hotel-estate.netlify.app/

## About the Project

This project was created to practice and demonstrate frontend development, responsive design, and website layout skills.
